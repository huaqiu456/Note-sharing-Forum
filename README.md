## 技术栈速览

- **框架**：Spring Boot 3.0.2、Spring Cloud Gateway、Spring Cloud Alibaba Nacos、OpenFeign
- **存储**：MySQL（业务数据 + Leaf 号段）、Redis（缓存/会话/权限/布隆过滤器）
- **搜索**：Meilisearch
- **对象存储**：MinIO 兼容接口（当前部署为 vaults3）
- **鉴权**：Sa-Token（网关统一鉴权 + RBAC 权限）
- **前端**：Vue3 + TypeScript + Vite + Element Plus + Pinia，Nginx 托管
- **部署**：Docker Compose（前端 8087，网关 8000）
