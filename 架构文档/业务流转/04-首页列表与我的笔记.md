# 业务流转：首页列表与我的笔记

## 一、首页笔记列表

### 请求

```
GET /note/list?page=1&size=10
```

### 流程

```
前端 → 网关（校验登录）→ note 服务
  1. 计算 offset = (page - 1) * size
  2. 查公开正常笔记 ID：
       SELECT id FROM t_note
       WHERE visible = 0 AND status = 1
       ORDER BY create_time DESC
       LIMIT offset, size
  3. 统计总数 countPublic()
  4. 逐个按 ID 查元数据，组装列表项
       { noteId, title, imgUris, creatorId, createTime }
  5. 返回 { total, list }
```

### 排序规则

按**发布时间倒序**（`create_time DESC`）。

### 前端

- 首页（`/home`）展示封面、标题、用户ID、发布时间。
- 底部分页组件：每页 10 条，支持上一页/下一页/页码跳转。
- 点击卡片进入详情页。

## 二、我的笔记

### 请求

```
GET /note/mine?page=1&size=10
```

### 流程

```
  1. 从登录上下文取当前 userId（LoginUserContextHolder）
       └─ 为空 → 返回「未登录」
  2. 查该用户的笔记 ID：
       SELECT id FROM t_note
       WHERE creator_id = #{creatorId}
       ORDER BY create_time DESC
       LIMIT offset, size
  3. 统计 countMy(creatorId)
  4. 组装列表返回
```

### 前端

- 「我的」页（`/profile`）上半部分展示用户资料，下半部分展示我的笔记列表。
- 同样支持分页与跳转。

## 两者对比

| 项 | 首页列表 | 我的笔记 |
| --- | --- | --- |
| 路径 | `/note/list` | `/note/mine` |
| 过滤条件 | `visible=0 AND status=1` | `creator_id = 当前用户` |
| 数据范围 | 所有公开正常笔记 | 仅自己 |
| 权限 | 登录即可 | 登录即可 |
| 排序 | `create_time DESC` | `create_time DESC` |
