# 业务流转：搜索笔记

## 涉及组件

前端 → 网关 → note 服务 → Meilisearch → MySQL

## 请求

```
POST /note/search
body: { keyword, page, size, type? }
```

## 流程

```
1. 前端提交关键词
   → 网关（校验登录）
   → note 服务 NoteServiceImpl.searchNote

2. 调 Meilisearch 搜索
   NoteSearchServiceImpl.searchNoteIds(keyword, page, size, type)
     - 索引：note
     - 过滤条件：visible = 0 AND status = 1（可选叠加 type）
     - 分页：limit = size，offset = (page-1)*size
     - 返回命中的 noteId 列表

3. 按 noteId 回 MySQL 组装列表项
   { noteId, title, imgUris, creatorId, updateTime }

4. 返回列表
```

## 索引同步来源

| 触发点 | 动作 |
| --- | --- |
| 发布笔记成功 | `noteSearchService.indexNote(note)` |
| 更新笔记成功 | 重新查完整笔记后 `indexNote` |

索引文档字段：

```json
{
  "noteId": 100,
  "title": "...",
  "content": "...",
  "topicName": "...",
  "type": 0,
  "visible": 0,
  "status": 1,
  "creatorId": 2,
  "updateTime": "..."
}
```

## 索引设置

在服务启动时（`@PostConstruct`）创建并配置：

| 配置项 | 值 |
| --- | --- |
| 主键 | `noteId` |
| searchable | `title`、`content`、`topicName` |
| filterable | `type`、`visible`、`status` |
| sortable | `updateTime` |

## 关键点

| 点 | 说明 |
| --- | --- |
| 一致性 | MySQL 为准，Meilisearch 最终一致 |
| 失败处理 | 搜索异常时返回空列表并记录日志 |
| 类型转换 | Meilisearch 返回的数字可能是 Double，需 `((Number) id).longValue()` |
| 前端 | 展示封面、标题、时间，点击进入详情 |
