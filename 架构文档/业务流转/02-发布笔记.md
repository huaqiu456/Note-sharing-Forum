# 业务流转：发布笔记

## 涉及组件

前端 → 网关（权限校验）→ note 服务 → ID服务 / MySQL / Redis / Meilisearch

## 前置条件

- 已登录，请求头带 `Authorization`。
- 当前用户拥有 `app:note:publish` 权限（admin 角色）。
- 图片/视频已先通过 `/file/upload` 上传完成。

## 完整流程

```
1. 前端上传图片
   POST /file/upload  (multipart)
     → 网关 → oss 服务
     → 上传到 MinIO bucket xiaohashu
     → 返回 /images/{objectName}

2. 前端提交发布
   POST /note/publish
     body: { type, title, content, imgUris[] 或 videoUris, topicId }
     → 网关：
          a. 校验登录态
          b. 校验 app:note:publish 权限   ← 普通用户在此被拒（403）
          c. 注入 userId 请求头
     → note 服务：NoteServiceImpl.publishNote
          a. 校验笔记类型（0 图文 / 1 视频）
          b. 图片来源：校验非空且 ≤ 8 张，逗号拼接
             （视频来源：校验链接非空）
          c. 若带 topicId，查 t_topic 取话题名
          d. Feign → ID服务 取 leaf-segment-test 生成 noteId
          e. 组装 Note 实体（含 content 正文）
          f. INSERT t_note
          g. 布隆过滤器 add(noteId)
          h. 同步 Meilisearch 索引 noteSearchService.indexNote(note)
     → 返回 Response.success()
```

## 数据落库

| 数据 | 位置 |
| --- | --- |
| 笔记元数据 + 正文 | MySQL `t_note`（`content` 字段） |
| 图片/视频 | MinIO 对象存储 |
| 搜索索引 | Meilisearch 索引 `note` |
| 布隆过滤器 | Redis Redisson `note:bloom` |

## 权限失败处理

普通用户提交时：

1. 网关 `StpUtil.checkPermission("app:note:publish")` 抛出 `NotPermissionException`。
2. `GlobalExceptionHandler` 返回 **403**。
3. 前端 axios 拦截器提示「权限不足，无法发布」，**不跳转登录页**。

## 关键点

| 点 | 说明 |
| --- | --- |
| 正文存储 | 直存 MySQL `t_note.content`，不再依赖 Cassandra/KV |
| 笔记类型校验 | 图文必须至少 1 张图且 ≤ 8 张；视频必须非空 |
| 事务 | 发布本身未加事务，正文与元数据同表写入 |
| 搜索同步 | 同步调用 Meilisearch，失败仅记录日志不影响发布 |
