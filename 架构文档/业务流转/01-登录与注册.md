# 业务流转：登录与注册

## 涉及组件

前端 → 网关 → auth 服务 → Redis / MySQL / ID服务

## 流程一：发送验证码

```
前端 POST /auth/verification/code/send  { phone }
  → 网关：白名单，直接放行
  → auth:VerificationCodeServiceImpl
      1. 检查 Redis verification_code:{phone} 是否已存在（防频繁）
      2. 生成 6 位随机码
      3. 线程池异步调用阿里云短信发送
      4. 写入 Redis，TTL 3 分钟
```

返回：`{"success":true}`

## 流程二：验证码登录（未注册则自动注册）

```
前端 POST /auth/login  { phone, code, type: 1 }
  → 网关：白名单，直接放行
  → auth:UserServiceImpl.loginandRegister
      1. 校验 code 与 Redis verification_code:{phone} 一致
      2. 查 t_user（按手机号）
          ├─ 不存在 → registerUser()   ← 自动注册
          └─ 存在   → 取 userId
      3. StpUtil.login(userId)
      4. 返回 token
```

### 自动注册子流程

```
registerUser(phone)  [事务]
  1. Feign → ID服务 取 leaf-segment-xiaohashu-id
  2. Feign → ID服务 取 leaf-segment-user-id
  3. INSERT t_user（昵称默认「小红薯{小红书号}」）
  4. INSERT t_user_role_rel（role_id = 1，普通用户）
  5. Redis SET user:roles:{userId} = ["common"]
```

> 注册依赖 ID 服务：若 `leaf_alloc` 缺少 `leaf-segment-user-id` / `leaf-segment-xiaohashu-id`，注册会失败并回滚。

## 流程三：密码登录

```
前端 POST /auth/login  { phone, password, type: 2 }
  → 查询 t_user
       ├─ 不存在 → 提示未注册
       └─ 存在   → BCrypt 校验密码
  → StpUtil.login(userId) → 返回 token
```

## 流程四：登出

```
前端 POST /auth/logout   （携带 Authorization）
  → 网关：校验登录态
  → auth：StpUtil.logout(userId)
```

## 前端处理

- 登录成功后把 token 存入 `localStorage`（key：`xiaohashu_token`）。
- 后续请求由 axios 拦截器自动携带 `Authorization` 头。

## 关键点

| 点 | 说明 |
| --- | --- |
| 验证码存储 | Redis `verification_code:{phone}`，TTL 3 分钟 |
| 自动注册 | 验证码登录时若手机号不存在则自动注册 |
| 默认角色 | `common`（role_id = 1），常量写死在 `RoleConstants` |
| 角色缓存 | `user:roles:{userId}`，**只在注册时写入、永不过期** |
