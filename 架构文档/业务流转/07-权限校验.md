# 业务流转：权限校验（RBAC）

## 模型

| 角色 | role_key | 权限 |
| --- | --- | --- |
| 普通用户 | `common` | `app:note:view` |
| 管理员 | `admin` | `app:note:view`、`app:note:publish` |

## 数据表（以代码实际使用为准）

| 表 | 说明 |
| --- | --- |
| `t_role` | 角色 |
| `t_permission` | 权限（`type = 3` 表示 APP 端） |
| `t_role_permission_rel` | 角色-权限绑定（RolePermissionMapper 使用） |
| `t_user_role_rel` | 用户-角色绑定（UserRoleMapper 使用） |

> 注意：代码使用的是带 `_rel` 后缀的表名。

## Redis 结构

```
user:roles:{userId}          → ["common"]                 用户拥有哪些角色
role:permissions:{roleKey}   → ["app:note:view", ...]      角色拥有哪些权限
push.permission.flag         → 权限推送幂等标记（1 天）
```

数据来源：

- `user:roles:{userId}`：**注册时写入**，之后不再自动更新。
- `role:permissions:{roleKey}`：auth 服务启动时由 `PushRolePermissions2RedisRunner` 从数据库推送。

## 校验流程

```
请求到达网关
  1. SaReactorFilter 拦截
  2. 登录校验：除白名单外都要求登录
  3. 权限校验：/note/publish 要求 app:note:publish
        └─ StpUtil.checkPermission("app:note:publish")
              ↓
        StpInterfaceImpl.getPermissionList(loginId)
              ↓
        ① 读 Redis user:roles:{userId}  → ["common"]
        ② 逐个读 role:permissions:{roleKey}
        ③ 合并权限列表返回
  4. 校验通过 → 放行；否则抛异常
```

## 异常与响应

| 场景 | 异常 | HTTP | 前端行为 |
| --- | --- | --- | --- |
| 未登录 | `NotLoginException` | 401 | 清 token，跳登录页 |
| 已登录但无权限 | `NotPermissionException` | 403 | 提示「权限不足，无法发布」，不跳登录 |

## 接口权限矩阵

| 接口 | 要求 |
| --- | --- |
| `POST /note/publish` | 需 `app:note:publish` |
| `GET /note/list` | 登录 |
| `POST /note/detail` | 登录 |
| `POST /note/search` | 登录 |
| `GET /note/mine` | 登录 |
| `POST /user/me`、`POST /user/update` | 登录 |
| `POST /auth/password/update` | 登录 |

## 变更权限数据后的必要操作

```
1. 修改数据库（t_role_permission_rel / t_user_role_rel）
2. redis-cli DEL push.permission.flag      清掉推送幂等标记
3. 重启 xiaohashu-auth                     重新推送角色权限
4. 若用户角色发生变化，还需同步其角色缓存：
   redis-cli SET user:roles:{userId} '"[\"common\",\"admin\"]"'
5. 重启/重新构建网关（代码变更时）
```

## 常见问题

| 现象 | 原因 |
| --- | --- |
| admin 也无法发布 | 权限未推送到 Redis（未清 flag 或未重启 auth） |
| 普通用户能发布 | 角色权限绑定错误（如 common 绑了 publish），或网关非最新构建 |
| 用户无任何权限 | `user:roles:{userId}` 不存在或角色值与数据库不一致 |

## 验证命令

```bash
redis-cli GET user:roles:2
redis-cli GET role:permissions:common
redis-cli GET role:permissions:admin

# 数据库核对
SELECT r.role_key, p.permission_key
FROM t_role_permission_rel rp
JOIN t_role r ON r.id = rp.role_id
JOIN t_permission p ON p.id = rp.permission_id;
```
