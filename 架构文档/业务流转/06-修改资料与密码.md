# 业务流转：修改资料与密码

两类用户（普通用户 / 管理员）都可以修改自己的资料和密码。

## 一、修改个人资料

### 请求

```
POST /user/update   (multipart/form-data)
  nickname / sex / birthday / introduction / avatar(文件) / backgroundImg(文件)
```

### 流程

```
1. 前端「我的」页点击「编辑资料」，弹窗回填当前资料
   （数据来自 POST /user/me）

2. 提交后 → 网关（校验登录，注入 userId）
   → user 服务 UserServiceImpl.updateUserInfo
        a. 从 LoginUserContextHolder 取当前 userId
        b. 逐项校验：
             - 昵称：正则校验
             - 小红书号：正则校验
             - 性别：枚举校验（0 女 / 1 男）
             - 简介：长度 ≤ 100
        c. 头像/背景图：调 OSS 服务上传，拿到 URL
        d. 更新 t_user
        e. 删除 Redis 缓存 user:info{userId}   ← 防止读到旧数据
        f. 返回成功

3. 前端重新调用 /user/me 刷新展示
```

### 涉及接口

| 接口 | 说明 |
| --- | --- |
| `POST /user/me` | 查询当前登录用户完整资料 |
| `POST /user/update` | 提交修改（multipart） |
| `POST /file/upload` | 头像/背景图上传（user 服务内部调 OSS） |

## 二、修改密码

### 请求

```
POST /auth/password/update   { password }
```

### 流程

```
1. 前端「我的」页点击「修改密码」，弹窗输入新密码 + 确认密码
   （前端校验：非空、两次一致）

2. 提交 → 网关（校验登录，注入 userId）
   → auth 服务 UserServiceImpl.updatePassword
        a. 取当前 userId
        b. BCrypt 加密新密码
        c. 更新 t_user.password
        d. 返回成功

3. 下次登录使用新密码
```

### 注意

- 当前实现**不校验旧密码**，只要求登录态。
- 修改密码不影响已签发的 token。

## 权限说明

这两类操作都**只要求登录**，不要求 `app:note:publish` 权限，因此普通用户和管理员都能操作。
