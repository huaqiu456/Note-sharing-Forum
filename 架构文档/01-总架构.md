# 总架构


## 二、服务清单

| 服务 | 端口 | 职责 | 主要依赖 |
| --- | --- | --- | --- |
| xiaohashu-gateway | 8000 | 统一入口、路由、Sa-Token 鉴权、注入 userId | Nacos、Redis |
| xiaohashu-auth | 8080 | 登录/注册、登出、改密码、验证码、RBAC 权限推送 | MySQL、Redis、Nacos、ID服务 |
| xiaohashu-user | 8082 | 用户资料查询/修改、头像上传 | MySQL、Redis、Nacos、OSS |
| xiaohashu-note | 8086 | 笔记发布/详情/更新/列表/搜索 | MySQL、Redis、Nacos、Meilisearch、ID服务、用户服务 |
| xiaohashu-oss-biz | 8081 | 文件上传、图片访问路径 | Nacos、MinIO |
| xiaohashu-distributed-id-generator-biz | 8085 | 号段模式分布式ID | MySQL(leaf)、Nacos |
| xiaohashu-web | 8087→80 | 前端静态资源 + 反向代理 | gateway、oss |

## 三、网关路由

| 路径 | 目标服务 | 说明 |
| --- | --- | --- |
| `/auth/**` | lb://xiaohashu-auth | 剥掉 `/auth` 前缀（auth 服务自身无该前缀） |
| `/user/**` | lb://xiaohashu-user | 保留前缀 |
| `/note/**` | lb://xiaohashu-note | 保留前缀 |
| `/file/**` | lb://xiaohashu-oss | 保留前缀 |

## 四、服务间调用（OpenFeign）

| 调用方 | 被调用方 | 用途 |
| --- | --- | --- |
| note | xiaohashu-user | 查笔记关联用户信息 |
| note | xiaohashu-distributed-id-generator | 生成笔记ID |
| auth | xiaohashu-distributed-id-generator | 生成用户ID/小红书号 |
| user | xiaohashu-oss | 上传头像/背景图 |

> Feign 请求会通过 `AddUserId2RequestInterceptor` 透传 `userId` 请求头。

## 五、中间件

| 中间件 | 用途 | 关键说明 |
| --- | --- | --- |
| MySQL `xiaohashu` | 用户、角色权限、笔记、话题 | 业务主库 |
| MySQL `leaf` | `leaf_alloc` 号段表 | ID 生成服务专用 |
| Redis | 会话、缓存、权限、布隆过滤器 | 多服务共用 |
| Nacos | 服务注册/发现、配置 | 网关负载均衡依赖它 |
| Meilisearch | 笔记全文搜索 | 索引名 `note` |
| MinIO(vaults3) | 图片/视频对象存储 | 返回相对路径 `/images/xxx` |

## 六、数据存储划分

| 数据 | 存储位置 | 说明 |
| --- | --- | --- |
| 用户账号、角色、权限 | MySQL `t_user` / `t_role` / `t_permission` / `t_role_permission_rel` / `t_user_role_rel` | RBAC |
| 笔记元数据 + 正文 | MySQL `t_note`（正文为 `content` 列） | 正文已由 Cassandra 迁回 |
| 话题/频道 | MySQL `t_topic` / `t_channel` | 笔记附属 |
| 笔记搜索索引 | Meilisearch `note` | 最终一致 |
| 笔记缓存 | Redis `note:{noteId}` | 详情缓存 |
| 用户缓存 | Redis `user:info{userId}` | 用户信息缓存 |
| 验证码 | Redis `verification_code:{phone}` | 3 分钟有效 |
| 用户-角色 | Redis `user:roles:{userId}` | 网关鉴权用 |
| 角色-权限 | Redis `role:permissions:{roleKey}` | 网关鉴权用 |
| 笔记布隆过滤器 | Redis Redisson `note:bloom` | 缓存穿透防护 |
| 笔记ID号段 | MySQL `leaf_alloc` | biz_tag：`leaf-segment-test` |

## 七、鉴权总览

- **登录态**：Sa-Token，token 放在 `Authorization` 请求头；网关统一校验，白名单为 `/auth/login`、`/auth/verification/code/send`。
- **权限**：网关按路径校验，如 `/note/publish` 需要 `app:note:publish`。
- **错误码**：未登录 → 401；已登录但无权限 → 403。
- **userId 透传**：网关解析登录态后写入请求头 `userId`，下游通过 `LoginUserContextHolder` 读取。

## 八、部署形态

- 全部业务服务 + 前端由 `docker-compose.yml` 编排，统一 `SPRING_PROFILES_ACTIVE=prod`。
- 配置分环境：`application-dev.yml`（本地）、`application-prod.yml`（容器，全部走环境变量）。
- 敏感信息集中在 `.env`（不提交），本地 dev 由 `spring.config.import` 读取，容器由 compose 注入。
- 对外仅暴露前端 8087（Nginx）与网关 8000；中间件不对公网开放。
